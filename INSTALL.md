# Установка QTranslateMac — пошагово, для тех, кто никогда не программировал

Эта инструкция рассчитана на полного новичка. Вам понадобится только Mac
с подключением к интернету и терпение на 10–15 минут.

Программа проверена в автоматической сборке на настоящем macOS (см. значок
"passing" в репозитории), но финальный шаг — «нажать хоткей и увидеть
перевод» — сможете подтвердить только вы сами на своём Mac: это единственное,
что нельзя проверить удалённо, потому что для этого нужен живой человек,
который выделяет текст мышкой.

## Шаг 1. Откройте Терминал

Терминал — это стандартное приложение macOS, ничего дополнительно ставить
не нужно.

1. Нажмите `⌘ (Command) + Пробел`, откроется поиск Spotlight.
2. Напечатайте `Терминал` (или `Terminal`) и нажмите `Enter`.
3. Откроется чёрное или белое окно с текстом — это и есть Терминал. Дальше
   вы будете копировать команды из этой инструкции и вставлять их туда
   (`⌘V`), затем нажимать `Enter`.

## Шаг 2. Проверьте, что Python уже есть

Современные Mac обычно уже имеют Python 3. Проверим:

```
python3 --version
```

Если увидите что-то вроде `Python 3.11.9` — всё в порядке, идите к шагу 3.

Если Терминал ответит `command not found`, установите Python:
1. Откройте в браузере https://www.python.org/downloads/macos/
2. Скачайте последнюю версию (жёлтая кнопка "Download Python 3.x.x").
3. Откройте скачанный `.pkg`-файл и пройдите установку, везде нажимая
   «Продолжить» / «Установить».
4. Закройте и снова откройте Терминал, повторите команду из шага 2.

## Шаг 3. Скачайте код программы

Самый простой способ — без установки дополнительных программ:

1. Откройте в браузере: https://github.com/er121/qtranslate-mac-py
2. Нажмите зелёную кнопку **Code**, затем **Download ZIP**.
3. Найдите скачанный файл `qtranslate-mac-py-main.zip` (обычно в папке
   «Загрузки») и дважды кликните — он распакуется в папку.
4. Переименуйте (необязательно) или просто запомните, где эта папка лежит,
   например `~/Downloads/qtranslate-mac-py-main`.

## Шаг 4. Перейдите в папку программы в Терминале

В Терминале наберите `cd ` (с пробелом после), затем перетащите саму папку
`qtranslate-mac-py-main` из Finder прямо в окно Терминала — путь подставится
автоматически. Нажмите `Enter`. Проверьте, что вы в нужном месте:

```
ls
```

Вы должны увидеть среди прочего `requirements.txt` и папку `qtranslate_mac`.

## Шаг 5. Установите зависимости

Это одна команда — она скачает и установит всё необходимое (переводчик,
доступ к системным функциям macOS и т.д.):

```
pip3 install -r requirements.txt
```

Подождите, пока команда закончится (может занять 1–3 минуты). Если в конце
нет слова `error` — всё установилось успешно.

## Шаг 6. Запустите программу

```
python3 -m qtranslate_mac.macapp
```

Если всё хорошо, ничего эффектного не произойдёт — в строке меню (верхняя
панель экрана, справа) появится маленькая иконка 🌐. Терминал должен
оставаться открытым, пока вы пользуетесь программой (можно свернуть окно,
но не закрывать).

## Шаг 7. Разрешите доступ (обязательно, один раз)

Программе нужно ваше разрешение, чтобы «подсматривать» выделенный текст и
нажимать горячие клавиши в других приложениях — так же, как это делает
оригинальный QTranslate на Windows. Без этого разрешения хоткеи и перевод
выделения работать не будут.

1. Откройте **Системные настройки** (значок шестерёнки).
2. Зайдите в **Конфиденциальность и безопасность** → **Универсальный доступ**
   (Privacy & Security → Accessibility).
3. Найдите в списке **Terminal** (или **python3** — в зависимости от версии
   macOS может появиться то или другое название).
4. Включите переключатель напротив него. Если элемента в списке ещё нет —
   нажмите `+` внизу списка и вручную добавьте: `Terminal.app` из папки
   `Программы/Утилиты`.
5. Может появиться системный запрос с кнопкой «Открыть настройки системы» —
   на него тоже можно нажать, это то же самое место.

После этого шага **перезапустите программу**: в Терминале нажмите `Ctrl+C`,
затем снова выполните команду из Шага 6.

## Шаг 8. Проверьте, что всё работает

1. Откройте любое приложение с текстом (например, Заметки, браузер).
2. Выделите мышью кусок текста на английском.
3. Нажмите одновременно `Option (⌥) + Command (⌘) + T`.
4. Рядом с курсором должно появиться окошко с переводом.

Если окошко не появилось — почти наверняка дело в Шаге 7 (разрешение
Accessibility): вернитесь туда и убедитесь, что переключатель включён именно
для того приложения, через которое вы запускаете команду (Terminal).

## Горячие клавиши по умолчанию

| Что делает | Комбинация |
|---|---|
| Показать перевод выделенного текста во всплывающем окне | `⌥ Option + ⌘ Command + T` |
| Заменить выделенный текст переводом на месте | `⌥ Option + ⌘ Command + R` |
| Выйти из программы | через иконку 🌐 в строке меню → «Выйти» |

Иконка 🌐 в строке меню — это главное меню программы: там же можно открыть
историю переводов, настройки и проверить статус разрешения доступа.

## Частые проблемы

- **«Слишком много запросов» / ошибка перевода** — бесплатный переводчик
  (Google Translate без ключа) иногда на короткое время ограничивает частые
  запросы. Подождите минуту и попробуйте снова.
- **Окошко перевода не появляется** — почти всегда это Шаг 7 (разрешение
  Accessibility). Перепроверьте его и перезапустите программу.
- **Хочу, чтобы программа запускалась сама при включении Mac** — это можно
  настроить позже отдельно (через «Системные настройки → Основные →
  Элементы входа»), добавив туда Terminal с этой командой; в первой версии
  это не автоматизировано.
- **Хочу закрыть Терминал, но чтобы программа продолжала работать** — в
  этой версии нельзя: приложение живёт, пока открыт Терминал (или хотя бы
  свёрнут, не закрыт). Упаковка в отдельное `.app`-приложение, которое можно
  запускать двойным кликом без Терминала — следующий шаг развития проекта.

## Если что-то пошло не так

Приложите точный текст ошибки из Терминала — по нему можно быстро понять,
в чём дело и поправить код.
